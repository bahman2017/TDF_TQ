# TDF_TQ Roadmap

Staged development plan for the Temporal Quantum Foundation. Each stage builds on the previous; scientific claims must respect the [claim maturity hierarchy](canonical_reference.md#claim-maturity-hierarchy).

| Stage | Name | Focus |
|-------|------|--------|
| **0** | Repository foundation | Package layout, docs, tests, outputs, canonical reference |
| **1** | Temporal packet primitives | Core packet types, validation, invariants |
| **2** | Emergent space toy model | Spatial neighborhoods, provisional metrics |
| **3** | Delta tau gravity proxy | Distributed effective gravity from temporal mismatch |
| **4** | Stable structure search | Localized particle **candidates** |
| **5** | Electron-like candidate criteria | Search criteria for stable charged-like structures |
| **6** | Propagating photon-like candidate | Radiation **candidates** |
| **7** | Energy and mass proxy | Toy energy/mass bookkeeping |
| **8** | GR effective tests | Compare toy limits to Newtonian/GR effective behavior |
| **9** | QM exploratory layer | Exploratory QM-like behavior (not assumed derived) |
| **10** | Documentation and Zenodo drafts | Publication-ready artifacts |

**Current stage:** 1 — Temporal packet primitives.
