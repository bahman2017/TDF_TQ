# TDF_TQ Roadmap

Staged development plan for the Temporal Quantum Foundation. Each stage builds on the previous; scientific claims must respect the [claim maturity hierarchy](canonical_reference.md#claim-maturity-hierarchy).

## Corrected stage sequence

| Stage | Name | Focus |
|-------|------|--------|
| **0** | Repository foundation | Package layout, docs, tests, outputs, canonical reference |
| **1** | Temporal packet primitives | Core packet types, validation, invariants |
| **2** | Emergent space toy model | Spatial neighborhoods, provisional metrics |
| **3** | Fundamental Temporal Actions | Minimal conservative Actions, metrics, catalog discipline |
| **4** | Emergent Structure Survey | Neutral seed surveys under Action catalog (toy criteria) |
| **5** | Emergent Geometry | Effective-geometry proxy tests from distributed Δτ |
| **6** | Stable Localized Structures | Persistence and robustness under allowed Actions only |
| **7** | Conserved Quantities | Integer and proxy conservation audits |
| **8** | QM Exploratory Layer | Phase/recurrence proxies only—not assumed QM derivation |
| **9** | Physics Recovery Tests | Weak-field / effective-limit comparisons—not claimed derivation |
| **10** | Documentation and Zenodo Drafts | Publication-ready artifacts |
