# Scientific Boundaries

This document states what the TDF_TQ repository **is** and **is not**.

## What this repository is

- A **time-first** exploratory program asking whether emergent space, effective gravity, stable particle-like structures, and later QM-like behavior can arise from temporal primitives.
- A collection of **working definitions**, **toy-model scaffolding**, and **deterministic tests**—not validated fundamental physics.

## What this repository is not

- **Not a completed theory.** Definitions and code are provisional.
- **Not experimental validation.** No repository artifact substitutes for experiment or peer-reviewed physics.
- **Not a replacement for GR or QM.** General relativity and quantum mechanics remain the established frameworks for their domains.

## Language conventions

- Use **“candidate”** for localized or propagating toy patterns until robust evidence exists—never imply derived electrons, photons, mass, charge, or spin.
- **Δτ by itself is not matter.** Temporal mismatch is a primitive quantity; matter-like behavior requires additional structure and evidence.
- **Deferred targets:** electron-like, photon-like, and Standard-Model particle language are legacy roadmap wording only; they are not near-term derived targets in the corrected [roadmap](roadmap.md).

## Interpretation caution

All current content should be read at maturity levels A–C in the [canonical reference](canonical_reference.md). Speculative interpretations (level D) must not be presented as validated physics (level E).
