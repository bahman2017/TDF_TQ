# TDF_TQ Canonical Reference

Concise locked definitions and claim maturity for the Temporal Quantum Foundation extension of the Time Delay Field program.

## Locked definitions

| Symbol / term | Definition |
|---------------|------------|
| **t_q** | Fundamental time quantum. |
| **tau (τ)** | Local temporal progression count; **tau = N_t**. |
| **Delta tau (Δτ)** | Temporal mismatch; **Δτ = ΔN_t**. |
| **N_t** | Larger **N_t** means slower local passage of time. |
| **Spatial distance** | Emergent, not fundamental. |
| **l_q** | Minimal spatial step; may be represented by the difference between neighboring spatial packet states. |
| **c** | Working speed limit; **c = l_q / t_q**. |
| **Δτ and matter** | Δτ does **not** automatically mean matter. |

### What Δτ may produce (working program scope)

1. Distributed effective gravity.
2. Stable localized structures as **particle candidates**.
3. Propagating structures as **radiation candidates**.

### Effective limits (to be tested later)

- GR and Newtonian dynamics are effective limits, not assumed derived here.
- QM is **not** assumed derived.

### Not yet derived

Electron, positron, photon, mass, charge, spin, energy, **ħ**, and **α** are not yet derived in this repository.
