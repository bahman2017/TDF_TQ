# Outputs

This directory stores **generated artifacts** from TDF_TQ stages: markdown reports, JSON summaries, CSV tables, and similar outputs produced by scripts or CI.

- Files here are **build products**, not source definitions.
- Stage reports document what was run, changed, and tested—not established physics.
- **No generated scientific claims** are validated yet; treat all outputs as toy-model or process documentation unless explicitly promoted in the canonical reference.

Example: `stage0_repository_foundation_report.md` records the Stage 0 repository setup.
